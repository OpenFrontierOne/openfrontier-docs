## Key insight

Every single one of these is either:

1. **A directory** (lists configs/prompts, no compute) — commodity
2. **An enterprise platform** (Salesforce, ServiceNow) — requires vendor lock-in
3. **A cloud runtime** (Replit, Cloudflare) — charges for compute

**None of them offer free, browser-based AI tools that run on the user's hardware.** That's our gap.
